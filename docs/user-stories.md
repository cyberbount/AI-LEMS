# User Stories

| ID | Story | Traceability |
|---|---|---|
| US-001 | As a lab user, I want to sign in so that the system can apply my role. | FR-001, FR-002 |
| US-002 | As a lab user, I want to see available equipment so that I can request a device. | FR-003, FR-004, FR-005 |
| US-003 | As a manager, I want to process borrow requests so that equipment is issued under approval. | FR-006, FR-007 |
| US-004 | As a technician, I want to complete maintenance records so that the maintenance state is recorded. | FR-008 |
| US-005 | As a manager, I want to inspect usage statistics so that I can understand recorded activity. | FR-009 |
| US-006 | As a lab user, I want to ask the local assistant about manuals so that I can find operational guidance. | FR-010, FR-011 |
| US-007 | As a manager or technician, I want an AI summary or inspection alert so that I can review the available evidence. | FR-012, FR-013 |
| US-008 | As a reviewer, I want document data to be traceable so that the retrieval source is identifiable. | FR-014 |
